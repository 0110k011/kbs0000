# 💰 Controle de Gastos Pessoais

Projeto de estudo em **Java**, criado com o objetivo de praticar manipulação de arrays de objetos, eventos, funções e persistência de dados no navegador.

## 📋 Sobre o projeto

O sistema permite cadastrar movimentações financeiras (entradas e saídas), calculando automaticamente o saldo total. Os dados ficam salvos no navegador através do `localStorage`, então nada se perde ao recarregar a página.

### Funcionalidades

- ✅ Cadastro de movimentações (descrição, valor, categoria e tipo);
- ✅ Validação dos campos do formulário;
- ✅ Cálculo automático de **Saldo**, **Entradas** e **Saídas**;
- ✅ Exclusão de movimentações;
- ✅ Filtro por categoria e por tipo;
- ✅ Cores diferentes para entradas e saídas;
- ✅ Mensagem exibida quando não há movimentações;
- ✅ Persistência de dados com `localStorage`.
